BLINKIT CLONE: AI INTEGRATION ROADMAP, OPTIONS & IMPLEMENTATION PLAN

1. PROJECT OVERVIEW & CURRENT TECH STACK
--------------------------------------------------------------------------------
This project is a full-stack quick-commerce grocery delivery platform (Blinkit Clone).

A. Frontend (Client):
   - Core Framework: React 19 (TypeScript) + Vite 8
   - Styling: Tailwind CSS v4 + Framer Motion (animations)
   - Routing: React Router v7 (react-router-dom)
   - Maps & Tracking: Leaflet & React-Leaflet
   - Icons & UI: Lucide React, Simple Icons, React Hot Toast
   - Utilities: Axios, jsPDF, html2canvas

B. Backend (Server):
   - Runtime & Framework: Node.js, Express.js 5 (TypeScript with tsx / nodemon)
   - Database: Neon Serverless PostgreSQL
   - ORM: Prisma ORM v7 (@prisma/client, @prisma/adapter-neon)
   - Authentication & Security: JWT (jsonwebtoken), bcrypt
   - Async Tasks & Event-Driven Workflows: Inngest
   - File & Media Storage: Cloudinary + Multer
   - Payments: Stripe API
   - Notifications: Nodemailer

2. AI INTEGRATION OPTIONS & USE CASES FOR THIS PROJECT
--------------------------------------------------------------------------------

Option 1: "Cook This Recipe" -> AI Recipe-to-Cart Converter
------------------------------------------------------------
- Concept: Users type "I want to cook Paneer Butter Masala for 4 people" or "healthy high-protein breakfast under 500 kcal".
- How AI Works: LLM (e.g., Gemini 1.5 Flash / OpenAI GPT-4o-mini) parses the dish, extracts the necessary ingredient list with estimated quantities, matches them against current product catalog in PostgreSQL/Prisma, and automatically adds or suggests all items to the cart in 1 click.
- Impact: Huge boost to Average Order Value (AOV) and user convenience.

Option 2: Smart Conversational Shopping Assistant ("Blinkit AI Copilot")
-----------------------------------------------------------------------
- Concept: A floating AI chatbot on the store UI to help users find groceries, substitute out-of-stock items, recommend snacks for movie night, or filter dietary requirements (e.g., "show gluten-free vegan snacks under Rs 200").
- How AI Works: LLM with Function Calling (Tool Calling). The AI calls internal backend endpoints (e.g. `searchProducts`, `checkStock`, `applyCoupon`) to execute actions on behalf of the user.

Option 3: AI Smart Search (Semantic Search + Typo Tolerance)
------------------------------------------------------------
- Concept: Users often search for colloquial names ("dahi", "haldi", "aloo", "energy drink for workout", "cleaning spray").
- How AI Works: Generate Vector Embeddings (via text-embedding-004 or OpenAI text-embedding-3-small) for product titles, categories, and descriptions. Store embeddings in PostgreSQL using pgvector (supported on Neon) or perform semantic matching using hybrid search (Keyword + Embedding).

Option 4: Snap & Shop / Fridge & Recipe Scanner (Vision AI)
----------------------------------------------------------
- Concept: User uploads a photo of their refrigerator, pantry shelf, or a handwritten grocery list.
- How AI Works: Multimodal Vision Model (e.g., Gemini 1.5 Flash Vision) detects items present, identifies missing staples (or reads handwritten text), and maps them to product IDs in the database for instant one-click ordering.

Option 5: AI Dynamic Delivery ETA & Route Optimization
-------------------------------------------------------
- Concept: Replace static 10-15 minute ETA with dynamic AI estimation considering weather, order size/weight, partner load, and live coordinates.
- How AI Works: Machine learning regression model or Inngest background job that dynamically computes transit times and suggests optimal delivery dispatch order.

Option 6: Predictive Re-Ordering & Personalized Deals
-----------------------------------------------------
- Concept: Predict when a user will run out of recurring staples (milk, eggs, bread) based on previous order history intervals and send smart reminders/push notifications.
- How AI Works: Time-series analysis or lightweight LLM agent running periodically via Inngest cron jobs.

Option 7: Automated Customer Support & Instant Order Refund Triage
------------------------------------------------------------------
- Concept: Handle "item damaged", "wrong item delivered", or "delivery delayed" complaints autonomously.
- How AI Works: Vision AI inspects user-uploaded photos of damaged products, verifies order details against DB, and automatically initiates partial Stripe refunds or discount coupons within safe thresholds.

3. RECOMMENDED IMPLEMENTATION PLAN (STEP-BY-STEP)
--------------------------------------------------------------------------------

PHASE 1: Quickest High-Impact Win — Recipe-to-Cart & AI Search Bar
------------------------------------------------------------------
1. Provider Selection:
   - Google Gemini API (`@google/genai` or `@google/generative-ai`) or OpenAI API. (Gemini Flash is fast, cost-effective, and excels at structured JSON output).
2. Backend Endpoint (`/api/ai/recipe-to-cart`):
   - Input: `{ prompt: "Palak Paneer for 3 people" }`
   - AI Prompt: Enforce JSON Schema containing required ingredients and units.
   - Database Query: Search Prisma `Product` table for matching ingredients with `stock > 0`.
   - Response: List of matched `Product` objects with recommended quantities ready for cart addition.
3. Frontend Integration:
   - Add an "AI Chef / Recipe to Cart" banner & modal in the client.
   - User inputs prompt -> Receives structured grocery bundle -> Click "Add All to Cart".

PHASE 2: AI Shopping Assistant & Multimodal Vision
--------------------------------------------------
1. Chatbot Backend Endpoint (`/api/ai/chat`):
   - Streaming responses using Server-Sent Events (SSE) or WebSockets.
   - Enable Function Calling for:
     * `searchProducts(query, category, maxPrice)`
     * `getOffersAndDiscounts()`
     * `checkDeliveryTime(addressId)`
2. Vision Endpoint (`/api/ai/scan-list`):
   - Upload grocery list photo via existing Multer + Cloudinary setup.
   - Send image buffer/URL to Gemini 1.5 Flash Vision.
   - Return structured product list.

PHASE 3: Vector Embeddings & Hybrid Search (pgvector on Neon)
-------------------------------------------------------------
1. Enable `pgvector` extension in Neon PostgreSQL.
2. Update Prisma Schema to include embedding vectors:
   - `model Product { ... embedding Unsupported("vector(768)")? }`
3. Generate embeddings during product creation/updates in Prisma.
4. Implement cosine similarity search: `SELECT * FROM "Product" ORDER BY embedding <=> $vector LIMIT 10;`.

PHASE 4: Autonomous Background Tasks with Inngest + AI
------------------------------------------------------
1. Recurring Inngest function running daily:
   - Scan user order history (e.g., milk purchased every 3 days).
   - If day == 3, trigger Nodemailer reminder with a 1-click cart replenishment link.
